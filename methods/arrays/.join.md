# .join(characters)

## Description

Join is a method that joins an array with a value

Strings, numbers, and booleans are formatted directly, so joining large scalar arrays avoids per-item generic formatting overhead.
Null values are written as `"null"` and never expose Go's internal nil representation.

## Parameters

Join takes the value to join the array with as a parameter.

## Usage On Arrays

```javascript
arr = ["wow","hello","world"]
// setup the array

log arr.join("!")
// returns "wow!hello!world"
// the array was joined with "!"
```
