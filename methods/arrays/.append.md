# .append(val)

## Description

Pushes `val` onto the **end** of the array and **returns the array itself** (enabling chaining).

## Parameters

* **val** - value to push.

Because it returns the same array reference, calls can be chained and every
call mutates the original array:

```javascript
arr = []
result = arr.append(1).append(2).append(3)
log result        // [1, 2, 3]
log arr           // [1, 2, 3]
log result == arr // true
```

## Usage

```javascript
arr = [1,2]
arr.append(3)
log arr // [1,2,3]
```
