# .JsonParse()

> ⚠️ **Not a method in the current OSL CLI.** Use the [`json` package](../../packages/json.md) instead: `json.parse(value, {type: "object" | "array"})` returns a [`Result`](../../packages/result.md).

## Replacement

```javascript
import "std:json"

auto parsed = json.parse("{\"x\":10,\"y\":20}", {type: "object"})
if parsed.isOk() (
  object data = parsed.unwrap().assert(object)
  log data.x // 10
)
```
