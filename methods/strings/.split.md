# .split(characters)

## Description

Split takes in a string and creates a `string[]` of parts based on the separator. The returned type
is preserved through array methods such as `.reverse()`.

## Parameters

Split needs the characters to split the array by

## Usage On Strings

```javascript
num = "hello world, im doing pretty well"

log num.split(" ")
// ["hello","world,","im","doing","pretty","well"]
```
