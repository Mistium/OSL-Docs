# .padEnd(padding, length)

## Description

Returns a string padded at the end to exactly `length` Unicode characters.

## Parameters

`padding` is repeated and truncated as needed. An empty padding string, or a target length no
greater than the current length, returns the original string.

## Usage On Strings

```javascript
num = "1"

log num.padEnd("0", 10)
// 1000000000

log "猫".padEnd("🐾x", 4)
// 猫🐾x🐾
```
