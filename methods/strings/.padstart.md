# .padStart(padding, length)

## Description

Returns a string padded at the start to exactly `length` Unicode characters.

## Parameters

`padding` is repeated and truncated as needed. An empty padding string, or a target length no
greater than the current length, returns the original string.

## Usage On Strings

```javascript
num = "1"

log num.padStart("0", 10)
// 0000000001

log "猫".padStart("🐾x", 4)
// 🐾x🐾猫
```
