# s3

Use `s3` to upload, download and delete objects in Amazon S3 and S3-compatible storage such as R2
and MinIO, and to sign presigned URLs.

```osl
import "std:s3"
```

## Example

```osl
import "std:s3"
import "std:env"

*s3.Client bucket = s3.new({
  endpoint: "https://s3.us-east-1.amazonaws.com",
  bucket: "my-bucket",
  accessKeyId: env.require("AWS_ACCESS_KEY_ID"),
  secretAccessKey: env.require("AWS_SECRET_ACCESS_KEY")
})

bucket.upload("notes/hello.txt", "Hello from OSL", {contentType: "text/plain"})
log bucket.download("notes/hello.txt").toStr()

string link = bucket.presignURL("notes/hello.txt", {expires: 600000})
log link

bucket.delete("notes/hello.txt")
```

A missing object fails with `NotFoundError`:

```osl
import "std:s3"

*s3.Client bucket = s3.new({endpoint: "http://127.0.0.1:9000", bucket: "media"})
byte[] data = bucket.download("missing.png") catch (err) (
  if err.kind == "NotFoundError" (
    log "no such object"
  )
  return
)
log data.len
```

## API reference

### `s3`

| Method | Returns | Notes |
| --- | --- | --- |
| `s3.new(options)` | `*s3.Client` | A client for one bucket. Objects are addressed path-style, as `endpoint/bucket/key`. Throws `ValueError` when `endpoint` or `bucket` is missing or `endpoint` isn't an http or https URL. |

Options for `s3.new`:

| Key | Notes |
| --- | --- |
| `endpoint` | Required. The service URL, such as `"https://s3.us-east-1.amazonaws.com"` or `"https://<account>.r2.cloudflarestorage.com"`. |
| `bucket` | Required. |
| `region` | Signing region. Default `"us-east-1"`; R2 uses `"auto"`. |
| `accessKeyId`, `secretAccessKey` | Credentials. |
| `sessionToken` | For temporary credentials. |
| `publicURL` | Base URL that `client.public` builds on. |
| `timeout` | Milliseconds per request. Default 30000. |

### `*s3.Client`

| Method | Returns | Notes |
| --- | --- | --- |
| `client.upload(key: string, data: string \| byte[], options?)` | `result<unit, error>` | Stores `data` as `key`, replacing any object there. Options: `contentType` (default `"application/octet-stream"`), `contentEncoding` (such as `"gzip"`), `cacheControl`. |
| `client.uploadFile(key: string, path: string, options?)` | `result<unit, error>` | Stores a local file. Same options; `contentType` defaults to the type the file extension suggests. |
| `client.download(key: string)` | `result<byte[], error>` | The object's contents. |
| `client.downloadFile(key: string, path: string)` | `result<unit, error>` | Saves the object to `path`, replacing the file. A partly written file is removed. |
| `client.delete(key: string)` | `result<unit, error>` | Removes the object. Deleting a key that doesn't exist succeeds, as in S3. |
| `client.presignURL(key: string, options?)` | `string` | A URL granting one kind of access to `key` without credentials. Options: `method` (default `"GET"`; `"PUT"` lets the holder upload), `expires` (ms, default 3600000; whole seconds from 1 second to 7 days), `contentLength` (bytes; the upload must then be exactly that size). |
| `client.public(key: string)` | `string` | `publicURL/key` when the client has `publicURL`, otherwise `endpoint/bucket/key`. Only useful when the bucket allows public reads. |
| `client.endpoint()` | `string` | The service URL. |
| `client.bucket()` | `string` | The bucket name. |
| `client.region()` | `string` | The signing region. |

### Errors

| Kind | When |
| --- | --- |
| `NotFoundError` | `download`/`downloadFile`: no such object. `uploadFile`: the local file doesn't exist. |
| `PermissionError` | The credentials are refused or access is denied, or a local file can't be read or written. |
| `NetworkError`, `TimeoutError` | The service can't be reached. |
| `IOError` | `downloadFile` can't write `path`. |
| `RuntimeError` | Any other error response from the service. |
| `ValueError` (thrown) | An empty key or an out-of-range `presignURL` option. |
| `TypeError` (thrown) | `upload` got something other than a string or `byte[]`. |

## Deprecated

These still work for one release and draw an `OSL-DEPRECATED` warning.

| Deprecated | Use instead |
| --- | --- |
| `client.put({key, body, content_type, content_encoding})` (returned `{ok, status, body, headers}` or `{ok: false, error}`) | `client.upload(key, data, {contentType, contentEncoding})` |
| `client.get({key})` | `client.download(key)`, which fails with `NotFoundError` for a missing object |
| `client.remove({key})` | `client.delete(key)` |
| `client.presign({key, expires, method, content_length})` (`expires` in seconds) | `client.presignURL(key, {expires: ms, method, contentLength})` |

`s3.new` still accepts the old snake_case option names `access_key_id`, `secret_access_key`,
`session_token` and `public_url`; use the camelCase names above.

The client no longer exposes its credentials or signing internals: `client.access()`,
`client.secret()`, `client.cfgStr`, `client.cfgDef`, `client.host()`, `client.sign` and the other
helper methods were removed.
