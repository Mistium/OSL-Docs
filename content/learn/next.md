# What's next

You've covered the whole language: values and types, control flow, functions, your own types, errors, iterators, modules, threads, tests and Go. That's everything you need to write real programs.

## Explore the standard library

OSL ships with packages for servers, databases, files, images, games, cryptography and more. Each [package page](../packages/index.md) starts with a tutorial and ends with every function the package has.

## Look things up

The [reference](../reference/index.md) is for when you know what you want and need the exact details: every operator, every built-in method, the command line, Opal and every compiler diagnostic.

## Keep a playground open

The [playground](/playground) runs the real compiler in your browser. It's the quickest way to try an idea, and a link to it shares your code.

## Get involved

OSL is open source. The compiler, the standard library and these docs all welcome fixes and ideas:

- The compiler: [git.rotur.dev/osl/.go](https://git.rotur.dev/osl/.go)
- These docs: [github.com/Mistium/OSL-Docs](https://github.com/Mistium/OSL-Docs)
