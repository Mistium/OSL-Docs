# Build

Each project starts with a few lines that do something and grows one small step at a time. The program sits beside the text, the lines each step adds are highlighted, and a "try it" tab runs it. Quizzes and challenges along the way check that it stuck.

They assume you've done [the course](../learn/index.md).
