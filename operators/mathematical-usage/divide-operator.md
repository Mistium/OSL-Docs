# Divide Operator (/)

You can use the simple / operator when you want to divide a value by another

```javascript
log 10 / 5
// does a division on its two operands and returns 2
// this is doing 10 divided by 5
```

Dividing two integer values uses integer division, so `7 / 2` returns `3`.
If either value is a decimal number, the result keeps the fraction:
`7.0 / 2` returns `3.5`.
